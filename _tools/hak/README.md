# hak — 손풀이 PDF로 전자칠판 수업 화면 만들기

`_` 로 시작하는 폴더라 GitHub Pages 사이트에는 공개되지 않는다.

| 파일 | 하는 일 |
|---|---|
| `hakbuild.py <cfg> <build>` | 손풀이 PDF + 문제만 PDF → `build/data.json`, 점검 그림 `build/check/*.png` |
| `loops.py <손풀이.pdf> <쪽> <out.png>` | 보라색 닫힌 테두리 → 단계 영역 후보 좌표(설정 초안용) |
| `embedapp.py <앱.html> <id> <build/apps/id.html>` | 교과서 설명앱을 흰 배경으로 바꿔 끼울 모듈로 변환 |
| `assemble.py <cfg> <build>` | `build/artifact.html`(아티팩트용) + `build/<OUT_NAME>`(깃허브·컴퓨터용) |
| `shots.js <html> <outdir> [index...]` | 4K 밀도 스크린샷(문제만 / 풀이 전체) |
| `at.js <html> 문항:단계:out.png ...` | 특정 단계 화면 스크린샷(단계 경계에 다른 단계 획이 섞였는지 확인) |
| `template.html` | 화면 틀(조작줄, 키보드·탭, 앱 끼우기) — 모든 단원이 함께 쓴다 |
| `retemplate.py <hak17.html> <out>` | 완성된 hak 파일에 지금의 template.html을 다시 입힘(PDF 없이). 틀 수정을 지난 단원에 넣을 때 |
| `makeindex.py <저장소> [아티팩트용]` | 저장소 최상위 html 목록으로 목차 `index.html` 생성(틀: `index_template.html`) |
| `notes/` | 오답노트 — 단원을 만들며 겪은 실수·결정·요령(README 참고) |
| `cfg17.py` | 17단원 설정 예시 — 새 단원은 이걸 복사해서 고친다 |
| `cfg18.py` | 18단원 설정 — 확률표 붙이기(`paste`)·행 형광 강조(`hl`) 예시, 개념 상자와 문항이 겹친 자리 지우기 |
| `cfg20.py` | 20단원 설정 — 번호만 다른 초록 단계(`cm` + 빈 단계), `drop`, 행 골라 붙이기(ROWPASTE), 표 테두리 메우기 |
| `cfg19.py` | 19단원 설정 — 분홍 네모 답 가리개·`join`·`CLEAN_FROM_MARK`·표 일부 붙이기(PART1) 예시 |
| `cfg22.py` | 22단원 설정 — 인쇄 문제만 줄여 재배치(`pieces`+`zoom`), 표 일부를 단계에 나타내기(ROWPASTE `step`), 문제 풀이 앱(15-etc1)을 흰 배경 앱 페이지로 끼움 |
| `cfg23.py` | 23단원 설정 — 보라 번호·분홍 네모가 없는 손풀이: 단계와 가리개(`covers`)를 cfg에서 직접 정함, 초록만 따로 단계(`g`) |
| `cfg21.py` | 21단원 설정 — 바꾼 쪽은 손풀이에서 펜 획을 지워 바탕으로, 번호 없는 개념 페이지(용어 정리), 인쇄 문제·표 축소 재배치 |
| `patches/hak19_dist.py` | hak19에 '표본평균분포' 개념 페이지 끼우기 — hak20 02·03 ① 손글씨를 PDF 없이 hak20.html에서 옮겨 배치(차례 가리개 예시) |
| `inkpaste.py` | 손풀이에 이미 쓴 손글씨 획(글자·기호)을 오려 색을 바꿔 다른 자리에 붙인 손풀이 사본을 만듦 — cfg `INKPASTE`. 빈 자리에 붙이고 `pieces`로 옮겨 새 단계로 씀(21 용어 정리 ⑤⑥) |
| `apps/` | 저장소 최상위에 따로 올리지 않는 개념 페이지 원본(예: `19binorm.html`) — `embedapp.py`로 끼움 |

좌표는 모두 페이지 가로 2000 기준 `[x0, y0, x1, y1]`.


항목 옵션(18단원에서 추가)
- `paste`: `[dict(page, src, at)]` 문제만 PDF의 인쇄물(확률표 등)을 `at`(왼쪽 위) 자리에 붙여 처음부터 보이게 함. 페이지 오른쪽·아래 밖도 허용(화면이 그만큼 넓어짐).
- `hl`: `[(단계index, 사각형)]` 그 단계에서 사각형에 노란 형광 강조(곱하기).
- `paste`에 `step=n`을 주면 처음엔 없다가 n단계에서 나타남. `src` 대신 `img='그림.png'`(500dpi 기준, cfg 위치 기준 경로)로 따로 만든 그림도 붙일 수 있음(예: 18단원 교과서 외 2 '목표 : 10m/a 의 값').
- `pieces`: `[dict(src=[사각형...], to=(dx, dy), base=True)]` 문항 조각(인쇄물·손글씨·펜 획)을 옮겨 새로 배치. steps·cm 좌표는 원래 위치로 쓰면 자동으로 옮겨지고, crop·paste·hl은 옮긴 뒤 위치로 쓴다. `base=False`면 그 조각의 인쇄물은 가져오지 않음.
- `follow`: 화면보다 긴 문항을 폭에만 맞춰 공통 배율로 크게 보이고, 아래쪽 단계를 쓸 때 화면이 따라 내려감(지금까지 쓴 것의 가장 아래와 지금 단계의 윗부분이 보이게). 화면 위 끝은 항상 줄 사이 빈 띠(gaps)에 맞춰 글자가 잘리지 않게 하고, 필요하면 문항 끝보다 더 올린다(아래는 빈 곳). 풀이 중 문제를 다시 보려면 화면 위아래 끌기·마우스 휠. 다음·이전을 누르면 다시 따라가기.
- `scale`: 공통 배율에 곱하는 값(예 0.9 = 이 문항만 90% 크기, follow 문항의 내려가는 양을 줄일 때).
- `pre`: 앞의 n개 단계는 처음부터 한꺼번에 보이고, 그 뒤 단계부터 한 단계씩(예: 개념 상자 ①~⑩은 바로 보이고 문제 풀이 ⑪부터). steps·hl·paste의 단계 번호는 원래 번호 그대로 쓴다.
- `solo`: 공통 배율 계산에서 빼는 문항(이 문항이 살짝 커서 다른 문항까지 작아지는 것을 막음).
- 노란 형광펜 획도 손글씨로 인식(구분선 등).

항목 옵션(19단원에서 추가)
- **분홍 네모 = 답 가리개**(색 `COVER_RGB`, 기본 (230,124,131)): 손풀이의 분홍 네모 안 획은 그 단계를 쓸 때 연분홍 네모로 가려지고, 교사가 네모를 누르면 그 답이 쓰인다. 그 단계 네모를 모두 열면 잠시 뒤 다음 단계로 자동 진행. 「다음」 버튼·키는 네모와 상관없이 다음 단계(남은 답은 바로 보임). 단, **마지막 단계**에 네모가 남아 있으면 「다음」 = 답 보이기, 한 번 더 = 다음 문제. 네모가 남아 있을 때 화면 빈 곳 탭은 무시. 「이전」은 그 단계 네모를 다시 가리고, 「풀이 전체」는 모두 연 상태.
- `join`: `[(사각형, (x, y))]` 사각형 안의 획(예: 81 위 초록 9², 옆 계산)을 점 (x, y)가 든 가리개에 묶어 그 네모를 열 때 함께 쓰이게 함.
- `CLEAN_FROM_MARK = {쪽: [사각형]}`: 손풀이 PDF에만 있는 인쇄물(교사가 붙인 표 그림 등)을 문제 바탕으로 씀.

cfg 기본 항목
- 상단: MARKED, CLEAN, OUT_NAME(`hak{단원}.html`), TITLE, BANNER, RULES, IGNORE, ITEMS, VECTOR(기본 True).
- ITEMS 순서 = 화면 순서. 문항 항목: page, sec(묶음 이름: 이항분포 복습/중단원 학습 점검/대단원 학습 평가/수학 익힘책/교과서 외 문제 등), num, crop(그 문항 칸 전체), steps[{rects, blue, g, prio}], blank, baseblank, cm, ghost, link, linkName.
- 앱 항목: `dict(kind='app', app='17normal', sec='개념 탐구 · 교과서', num='정규분포', toc='정규분포', group='중단원 학습 점검')`
- `embedapp.py`는 어두운 칠판색 → 흰 배경색으로 바꾼다. 앱마다 색이 다르면 COLOR_MAP 보강. (22) 문제 풀이 앱(math-lesson-app 형식)도 끼울 수 있음 — 스테이지 맞춤 끝이 `setTimeout(fitStage,t)`인 것도 인식.

화면 규격(template.html에 구현됨)
- 흰 배경(시험 기간 기준). 문항마다 내용 영역만 잘라 왼쪽 위에 붙이고, 문제 번호는 왼쪽 위, 좌우 여백 없음. 문제 바탕은 500dpi 그림, 손풀이는 펜 획(벡터).
- 공통 배율로 글자 크기 통일(화면 크기에 따라 실행 중 자동 계산, UNIFORM_TOL=0.9).
- 단계 보이기(19단원부터): 그 단계 영역이 **왼쪽 → 오른쪽으로 펼쳐짐**(펜 순서 쓰기 대신 — 수업에서 너무 오래 걸려서 바꿈). 영역 폭에 비례해 0.35~1.3초(WIPE_MIN_MS·WIPE_MAX_MS). 펼치는 도중 다음 → 즉시 완성, 한 번 더 → 다음 단계. 이전·문제만·풀이 전체·문항 이동은 즉시. 표 강조는 fade, 형광펜은 반투명 곱하기. 지난 단원은 `retemplate.py`로 다시 입힘(hak18 적용, hak17은 사용자가 원하지 않아 그대로).
- 맨 아래 한 줄: 왼쪽 문항 제목(+Link), 가운데 단원별 문항 목록, 오른쪽 문제만·풀이 전체·이전·다음·전체화면. 진행상황 표시 없음. 문항 번호 글자를 키우지 않는다. 묶음 이름(중단원·대단원·익힘책·교과서 외)은 넣어도 한 줄에 들어갈 때만 보이고 두 줄로 넘어가면 숨김(`labelFit()` — 창 폭이 아니라 실제로 재서 정함).
- 조작: 화면 탭·→·스페이스·PageDown 다음, ←·PageUp 이전, Home 문제만, End 풀이 전체.
- 앱 페이지: Shadow DOM에 넣어 상태 유지, 키보드·탭은 앱에 넘김(PageUp/PageDown만 이동). 앱은 공통 배율과 관계없이 화면에 맞춤.

항목 옵션(20단원에서 추가)
- `pieces`의 `zoom`: 그 조각을 첫 사각형 왼쪽 위 기준으로 줄임(예 0.82). steps·join 등은 원래 좌표로 쓰면 함께 변환됨.
- `drop`: `[사각형]` 점의 절반 이상이 이 안에 든 펜 획은 이 문항에서 뺌(옆 문항 음영 테두리가 칸 경계에 걸칠 때).
- 펜 획 배정 규칙: 점 절반 이상이 crop(여유 6) 밖이면 옆 문항 획으로 보고 뺌. 그림 판정 표가 모자라면 단계 사각형으로 정함. 가운데가 crop 밖인 분홍 네모도 뺌.
- `CLEAN_FROM_MARK` 복사 때 채도 높은 색(보라·초록 손글씨)은 흰색으로 지움.

항목 옵션(23단원에서 추가)
- `NUM_FMT = '모의고사 {}번'`(cfg 상단) 또는 항목 `label`: 아래 왼쪽 제목만 바꿈(문항 목록 번호는 그대로).
- 시험용 타이머 페이지 `apps/23timer.html`(25분, 시작·일시정지·±1분·종료음): 이미 모듈 형식이라 embedapp 없이 `build/apps/`에 복사하고 `kind:'app'` 항목으로 맨 앞에 둔다. 시간은 파일의 `LIMIT`.
- `norule: True`: 이 문항에서는 쪽 구분선(RULES) 제외를 끔 — `pieces`로 손풀이를 구분선 자리까지 옮겼을 때.
- `covers`: `[사각형]` 손풀이에 분홍 네모가 없을 때 cfg에서 직접 넣는 답 가리개(원래 좌표). 동작은 분홍 네모와 같고 `join`도 그대로 쓴다.

차례 가리개(19단원 표본평균분포에서 추가, template.html)
- 가리개에 `o`(0,1,2…)가 있으면 처음부터 모두 보이고, 「다음」(화면 탭·다음 차례 네모 탭)마다 o 순서대로 하나씩 열림. n = 가리개 수, 획·가리개 s=-1.
- 순서 밖 네모를 직접 누르면 그 네모만 열리고, 「다음」은 이미 연 차례를 건너뜀. `o`가 없는 보통 가리개 동작은 그대로.
