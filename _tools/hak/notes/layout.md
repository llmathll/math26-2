# 배치·크기 오답노트

## 표준정규분포표 등 참고 인쇄물 (18단원에서 정한 기준)
- 표가 필요한 문항은 문제 오른쪽 등 적절한 자리에 미리 붙이고(`paste`), 표 값을 쓰는 단계에 그 행을 노란 형광으로 강조(`hl`, cfg18의 `HL(at, '1.0', 단계번호)` 도우미).
- 표 때문에 문제가 아래로 밀리면 안 된다: 문제 번호는 항상 화면 맨 위 왼쪽. 표는 문제 번호 높이부터 오른쪽에 둔다.
- 자리가 없으면 처음엔 없다가 필요한 단계에 나타나게(`paste`의 `step`) 빈 곳(예: 왼쪽 아래)에 둔다. 이미 설명한 내용을 가리는 자리는 피한다.
- 표가 필요 없는 문항에는 넣지 않는다.
- 표 전체가 들어갈 자리가 없으면 머리 + 필요한 행 근처만 붙인다(cfg19 `PART1`: 머리 + 1.0~2.07). 그래도 모자라면 `pieces`로 풀이 칸을 조금 옮긴다(19의 18번: ①② 칸을 105 아래로).

## 공통 배율(글자 크기 통일)
- 공통 배율 = solo가 아닌 문항들의 꽉 차는 배율 중앙값 × UNIFORM_TOL(0.9) 이상인 문항들 중 가장 작은 배율. 그보다 큰 문항만 살짝 축소.
- 내용 영역이 가로 약 950, 세로 약 500(페이지 가로 2000 기준) 안에 들면 공통 배율로 나온다.
- 완성 후 문항별 배율을 찍어 축소된 문항이 몇 개·얼마나 작은지 사용자에게 알린다.

## 큰 문항 다루기 (먼저 시도할 순서)
1. `pieces`로 배치 바꾸기 — 옆 칸 개념 상자를 문제 오른쪽 위로, 긴 풀이 끝을 다음 줄로, 그래프를 빈 곳으로.
2. `follow` — 폭에만 맞춰 공통 배율로 크게, 아래 단계를 쓸 때 화면이 따라 내려감(↑문제 보기 버튼 있음). 내려가는 양이 크면 `scale`(예 0.9)로 조금 줄임.
3. `solo` — 살짝 큰 문항 하나가 다른 문항까지 작게 만들 때 공통 배율 계산에서 뺌.
