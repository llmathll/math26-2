# hak 오답노트

스킬(SKILL.md)에는 핵심 절차만 두고, 단원을 만들며 겪은 실수·결정·요령은 여기 쌓는다.
저장소에 있으므로 어느 대화에서든 읽고 고칠 수 있다(스킬 파일을 다시 올릴 필요 없음).

| 파일 | 언제 읽나 |
|---|---|
| `reading.md` | 손풀이 PDF를 읽고 cfg를 쓸 때 (보라색·번호·영역·특수 표시) |
| `steps.md` | 단계 상자를 정하고 점검할 때 (다음 단계 글자가 미리 보임, 빈 단계, 펜 획) |
| `layout.md` | 배치·크기 문제를 다룰 때 (표 붙이기, 조각 옮기기, 공통 배율, 긴 문항) |
| `saving.md` | 깃허브·컴퓨터에 저장할 때 |
| `feedback.md` | 사용자에게 손풀이 작성 요령을 알려 줄 때 |

## 쓰는 법
- 사용자가 고쳐 달라고 한 것 중 **다음 단원에서도 되풀이될 만한 것**만 적는다(그 단원에만 해당하면 cfg 주석으로).
- 형식: `- (단원) 증상 → 원인 → 해결` 한 줄. 이미 같은 내용이 있으면 새로 쓰지 말고 그 줄을 고친다.
- 오답노트를 고치면 `_tools/hak`의 다른 변경과 함께 커밋한다.
