최고차항의 계수가 1인 모든 사차함수 f(x)에 대하여 모든 f(−1)의 값의 합은?
(가) f(0) = 0
(나) 함수 f(|x−1|)은 x = 1에서 미분가능하다.
(다) 함수 |f(x) − f(1)|이 x = k에서 미분가능하지 않은 실수 k의 개수는 1이다.
① 조건 (가)상수항 결정
f(x) = x⁴ + ax³ + bx² + cx + d
f(0) = 0  ⟹  d = 0
② 조건 (나)평행이동으로 바꿔 보기
y = f(|x−1|)의 그래프를 x축 방향으로 −1만큼 평행이동하면  y = f(|x|)
평행이동은 미분가능성을 바꾸지 않으므로
f(|x−1|)이 x = 1에서 미분가능
⟺ f(|x|)가 x = 0에서 미분가능
③ 조건 (나)좌·우 미분계수
x > 0 : f(|x|) = f(x)  →  우미분계수 = f′(0)
x < 0 : f(|x|) = f(−x)  →  좌미분계수 = −f′(0)
두 값이 같아야 하므로  f′(0) = 0  ⟹  c = 0
④ 정리미지수가 둘로 줄었다
f(x) = x⁴ + ax³ + bx²
→ f(x)에는 일차항이 없다. ⑧·⑨단계에서 결정적으로 쓰인다.
⑤ 조건 (다)꺾임은 중복도가 결정한다
h(x) = f(x) − f(1)  (사차식, 항상 h(1) = 0)
|h(x)|가 x = k에서 미분불가능  ⟺  k가 중복도 1인 근
중복도가 2 이상이면 x축에 매끄럽게 붙는다 (오른쪽 비교)
⑥ 조건 (다)중복도 분포 전수조사
사차식의 근을 중복도로 나눈 모든 경우를 따져보면
단순근이 정확히 1개인 것은 (3중근) + (단순근) 뿐이다.
오른쪽 카드 8개를 눌러 꺾인 점의 개수를 직접 확인해 보자.
⑦ 식의 꼴h(1) = 0 을 붙이면
h(x) = (x−1)³(x−α)
또는
h(x) = (x−1)(x−β)³
⑧ 경우 ①일차항 계수 = 0
h(x) = (x−1)³(x−α) = (x³ − 3x² + 3x − 1)(x − α)
= x⁴ − (α+3)x³ + (3α+3)x² − (3α+1)x + α
−(3α+1) = 0  ⟹  α =  −13
f(x) = x⁴ −83x³ + 2x²  ⟹  f(−1) = 173
⑨ 경우 ②일차항 계수 = 0
h(x) = (x−1)(x−β)³ = (x − 1)(x³ − 3βx² + 3β²x − β³)
= x⁴ − (3β+1)x³ + (3β²+3β)x² − (β³+3β²)x + β³
β²(β+3) = 0  ⟹  β = 0 또는 β = −3  (β=1이면 4중근이라 제외)
β = 0 : f(x) = x⁴ − x³  ⟹  f(−1) = 2
β = −3 : f(x) = x⁴ + 8x³ + 18x²  ⟹  f(−1) = 11

173  + 2 + 11 =  563   정답 ①
