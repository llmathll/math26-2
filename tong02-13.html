최고차항의 계수가 1인 사차함수 — 모든 f(−1)의 값의 합
다음 조건을 만족시키는 최고차항의 계수가 1인 모든 사차함수 f(x)에 대하여 모든 f(−1)의 값의 합은?
(가) f(0) = 0
(나) 함수 f(|x−1|)은 x = 1에서 미분가능하다.
(다) 함수 |f(x) − f(1)|이 x = k에서 미분가능하지 않은 실수 k의 개수는 1이다.
STEP 1
(가)·(나)로 식 줄이기
평행이동 → f(|x|)의 미분가능성
f(x) = x⁴ + ax³ + bx²
STEP 2
(다) → 근의 중복도
|f(x)−f(1)|이 꺾이는 곳
= 중복도 1인 근
STEP 3
일차항 계수 = 0
남은 미지수 α, β를 결정하고
f(−1) 세 값을 모두 더하기
STEP 1 · 조건 (가), (나)
f(x) = x⁴ + ax³ + bx² + cx + d
(가) f(0) = 0  ⟹  d = 0
(나) y = f(|x−1|)의 그래프를
x축 방향으로 −1만큼 평행이동하면  y = f(|x|)
평행이동은 미분가능성을 바꾸지 않으므로
f(|x−1|)이 x=1에서 미분가능 ⟺ f(|x|)가 x=0에서 미분가능
x > 0 : f(|x|) = f(x)  →  우미분계수 = f′(0)
x < 0 : f(|x|) = f(−x)  →  좌미분계수 = −f′(0)
두 값이 같아야 하므로  f′(0) = 0 ⟹ c = 0
f(x) = x⁴ + ax³ + bx²
→ f(x)에는 일차항이 없다. STEP 3에서 결정적으로 쓰인다.
슬라이더로 c를 바꿔 보자 ( f(x) = x⁴ + cx 로 관찰 )
c 2.0
y = f(x)
y = f(|x|)
좌미분계수 −f′(0)
−2.0
우미분계수 f′(0)
2.0
x = 0 에서 꺾인다 — 미분불가능
※ 세로축은 모양이 잘 보이도록 확대 표시 (원점 부근은 실제 비율)
STEP 2 · 조건 (다)
h(x) = f(x) − f(1)  (사차식, 항상 h(1) = 0)
|f(x)−f(1)|이 꺾이는 곳은 근의 중복도가 결정한다
|h(x)|가 x = k에서 미분불가능 ⟺ k가 중복도 1인 근
단순근이 정확히 1개인 경우는 (3중근) + (단순근) 뿐이다. 그런데 h는 항상 x = 1을 근으로 가지므로
h(x) = (x−1)³(x−α)
또는
h(x) = (x−1)(x−β)³
카드를 모두 터치해 꺾인 점의 개수를 확인하자
y = h(x)
y = |h(x)|
위 카드를 눌러 보세요 (0 / 8)
※ 세로축은 모양이 잘 보이도록 확대 표시 (x축 부근은 실제 비율)
STEP 3 · f(x)에 일차항이 없다 ⟹ h(x)의 x 계수 = 0
경우 ①   h(x) = (x−1)³(x−α)
= (x³ − 3x² + 3x − 1)(x − α)
= x⁴ − (α+3)x³ + (3α+3)x² − (3α+1)x + α
−(3α+1) = 0  ⟹  α =  −13
경우 ②   h(x) = (x−1)(x−β)³
= (x − 1)(x³ − 3βx² + 3β²x − β³)
= x⁴ − (3β+1)x³ + (3β²+3β)x² − (β³+3β²)x + β³
β²(β+3) = 0  ⟹  β = 0 또는 β = −3  (β=1이면 4중근이라 제외)
