문제 ▾ 접기
최고차항의 계수가 1인 모든 사차함수 f(x)에 대하여 모든 f(−1)의 값의 합은?
(가)f(0) = 0
(나)함수 f(|x−1|)은 x = 1에서 미분가능하다.
(다)함수 |f(x) − f(1)|이 x = k에서 미분가능하지 않은 실수 k의 개수는 1이다.
① 조건 (가)상수항 결정
f(x) = x⁴ + ax³ + bx² + cx + d
f(0) = d = 0 ⟹ d = 0
오른쪽에서 d를 움직여 그래프를 원점에 맞춰 보자.
② 조건 (나)평행이동으로 바꿔 보기
y = f(|x−1|)을 x축 방향으로 −1만큼 평행이동 ⟹ y = f(|x|)
평행이동은 미분가능성을 바꾸지 않으므로
f(|x−1|)이 x = 1에서 미분가능
⟺ f(|x|)가 x = 0에서 미분가능
③ 조건 (나)좌·우 미분계수
x > 0 : f(|x|) = f(x) → f′(0)
x < 0 : f(|x|) = f(−x) → −f′(0)
두 값이 같아야 하므로
f′(0) = 0 ⟹ c = 0
④ 정리미지수가 둘로 줄었다
f(x) = x⁴ + ax³ + bx²
f(x)에는 일차항이 없다. ⑧·⑨단계에서 α, β를 정하는 유일한 조건이 된다.
⑤ 조건 (다)꺾임은 중복도가 결정한다
h(x) = f(x) − f(1)  (사차식, 항상 h(1) = 0)
|h(x)|가 x = k에서 미분불가능
⟺ k가 중복도 1인 근
중복도가 2 이상이면 x축에 매끄럽게 붙는다.
⑥ 조건 (다)중복도 분포 전수조사
사차식의 근을 중복도로 나눈 모든 경우 중
단순근이 정확히 1개인 것은
(3중근) + (단순근)
뿐이다.
오른쪽 카드 8개를 눌러 꺾인 점의 개수를 직접 확인해 보자.
⑦ 식의 꼴h(1) = 0 을 붙이면
h(x) = (x−1)³(x−α)
또는
h(x) = (x−1)(x−β)³
h(0) = −f(1)  ,  f(−1) = h(−1) + f(1)
계수를 모두 구하지 않고 h의 두 값만 계산하면 된다.
⑧ 경우 ①α 결정 → f(1) → f(−1)
(x−1)³(x−α) = (x³ − 3x² + 3x − 1)(x − α)
f에 일차항이 없으므로 h의 일차항 계수도 0
−(3α+1) = 0 ⟹ α = −13
x = 0 을 대입 : h(0) = f(0) − f(1) = −f(1)
(−1)³(−α) = α = −13 ⟹ f(1) = 13
x = −1 을 대입 : h(−1) = f(−1) − f(1)
(−2)³(−1 + 13) = 163
⟹ f(−1) = 163 + 13 = 173
⑨ 경우 ②β 결정 → f(1) → f(−1)
(x−1)(x−β)³ = (x − 1)(x³ − 3βx² + 3β²x − β³)
일차항 계수가 0 이어야 하므로
−(β³+3β²) = 0 ⟹ β = 0 또는 β = −3
(β = 1이면 4중근이 되어 제외)
h(0) = (−1)(−β)³ = β³ = −f(1) ⟹ f(1) = −β³
h(−1) = (−2)(−1−β)³ = 2(1+β)³
⟹ f(−1) = h(−1) + f(1) = 2(1+β)³ − β³
β = 0 : f(−1) = 2·1 − 0 = 2
β = −3 : f(−1) = 2(−2)³ + 27 = 11
